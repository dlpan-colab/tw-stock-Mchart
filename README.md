# 台股技術與籌碼分析系統（tw-stock-Mchart）

## 一、 系統模組架構
* `app.py`：主介面與狀態生命週期（唯一系統版本號權威源）。頂部採三主頁籤架構（`📊 操作儀錶板` / `📈 個股` / `⚙️ 參數設定`），預設收合側邊欄；「個股」主頁籤內含四大子頁籤（`📊 指標` / `💰 籌碼` / `📊 分點統計` / `📈 分點日況`）。
* `frontend.py`：Plotly 前端圖表、跨圖同步 JS 與分點雙頁籤（分點統計排行榜、分點日況逐日柱狀圖）HTML 渲染。
* `chart_builder.py`：K 線主圖、指標頁籤（KD/MACD/OBV/乖離率）與籌碼頁籤建置。
* `indicators.py`：均線、乖離率、技術指標、5MA 波段轉折、週轉率與大戶週對齊計算。
* `data_fetcher.py`：日 K 線、三大法人、資券、集保大戶、操作儀錶板報價與富邦分點爬蟲引擎。
* `storage.py`：本地 SQLite（`data_{code}.db`）與歷史紀錄管理（與操作儀錶板自選清單雙向同步）。
* `cloud_sync.py`：Google Drive 雙向同步（Service Account / Colab）。

## 二、 開發防呆憲法（新對話必讀，未經允許嚴禁產出程式碼）

### 1. 已驗證網路資料源清冊（嚴禁擅自替換或修改）
* **日 K 線與流通股數**：`yfinance`（主）＋ 證交所 `STOCK_DAY` / 櫃買 `st43_result.php`（補齊延遲日 K）。
* **三大法人**：證交所 `T86` / 櫃買 `3itrade_hedge_result.php`（主）＋ FinMind `TaiwanStockInstitutionalInvestorsBuySell`（備）。
* **融資融券**：FinMind `TaiwanStockMarginPurchaseShortSale`。
* **集保大戶持股**：單股 FinMind `TaiwanStockHoldingSharesPer`（取最新單一公告日 1～15 級）；批次集保開放資料 `opendata.tdcc.com.tw/getOD.ashx?id=1-5`（主）＋ FinMind（備）。
* **券商分點進出**：富邦 e點通（`fubon-ebrokerdj.fbs.com.tw`）。
  * **區間與單日進出排行（含歷史單日）**：統一使用 `z/zc/zco/zco.djhtm?a={code}&e={start_date}&f={end_date}`（單日查詢時 `e` 與 `f` 帶入同一交易日即可精準取得歷史單日排行，避免誤抓預設最新日）。
  * **網頁結構與正負號解讀鐵律**：頁面為**同一張 10 欄並排表格**（前 5 欄為買超券商、後 5 欄為賣超券商），且網站原始 HTML 中「賣超前 10 名」的買賣超張數欄位是以**正數**呈現，解析時必須強制正規化為負值（`-abs(net_val)`），前端統一顯示「買超紅字＋號、賣超綠字－號」。
  * **單一分點逐日進出明細**：由排行表分點名稱連結解析出 `z/zg/zgb/zgb0.djhtm` 明細網址（統一查詢參數 `B`），抓取各交易日買進、賣出與買賣超張數。

### 2. 核心量化演算法與顯示鐵律
* **5MA 波段轉折〔頭〕〔底〕**：站上 5 均波段取最高價標綠色〔頭〕；跌破 5 均波段取最低價標紅色〔底〕。**轉折邊界日必須同時列計前後兩波段**（最高價列入前波〔頭〕、最低價列入下波〔底〕）。
* **週轉率（轉手率）**：分母為「流通在外總股數扣除持股 1,000 張以上大戶持股比例（僅計千張以下流通股數）」；週轉率 ≥ 10% 標深藍 `▲`、≥ 20% 標金黃 `▼`。
* **集保大戶揭露時序**：集保於當週最後交易日之次日（週六）公布，**公布前當週交易日一律留空不呈現**（嚴禁沿用上週數值 forward-fill，也不可補 0）。
* **券商分點揭露時序**：富邦分點資料於當日盤後公布，**台灣時間 15:00（含）以前預設對齊前一交易日**作為分點基準日，避免盤中查無當日分點而顯示空白；15:00 以後對齊當日。

### 3. 圖表互動與座標軸鎖定鐵律
* **右邊界鎖定**：K 線主圖與同步副圖 X 軸右邊界永遠綁定最後一個交易日，不可向右拖曳留白。
* **主從縮放隔離**：**只有 K 線主圖可以縮放**（電腦版以**滑鼠滾輪上下**縮放，非滑動視窗拉桿）；所有副圖（不含分點柱狀圖）必須同步關注交易日且嚴禁個別放大縮小。
* **Y 軸鎖定與動態調整**：全圖表禁止上下移動（`fixedrange: true`），Y 軸最大／最小值必須隨可視 X 軸區間內資料動態調整。
* **分點每日柱狀圖**：以完整區間交易日陣列補 0 對齊、X 軸僅標示月份，且設定 `staticPlot: true` 徹底鎖死**禁止上下左右移動、手勢平移或縮放**。預設顯示**近 20 日**；因「📈 分點日況」位於預設未展開的子頁籤，**必須偵測容器可見寬度（`offsetWidth > 0`）後方可執行首次繪圖並明確鎖定外框像素寬度**，杜絕隱藏容器初次以預設 700px 繪製導致手機右側遭裁切。

### 4. UI 配置與狀態生命週期鐵律
* **三主頁籤與分點雙子頁籤架構**：
  * 主頁籤為 `📊 操作儀錶板`（與查詢歷史清單同步，顯示市/櫃、成交價、成交量與 5日/20日均線多空燈號）、`📈 個股`、`⚙️ 參數設定`。
  * 「個股」主頁籤內拆分為 `📊 指標`、`💰 籌碼`、`📊 分點統計`（當日／近 10 日／近 20 日／近 60 日排行榜）、`📈 分點日況`（前 5 名買賣超分點逐日進出柱狀圖）四大子頁籤。
* **歷史清單排序**：點擊「◀ 上一檔 / 下一檔 ▶」或自「📊 操作儀錶板」點擊股票名稱跳轉時，**維持查詢歷史清單原順序不置頂**；**直接輸入股票代碼**或**自查詢歷史清單勾選**時，該標的須**置頂**。
* **輸入框狀態同步**：外部按鈕或選單切換標的時，一律先寫入 `pending_stock_input`，於 `st.text_input(key="stock_input_box")` 實體化前 `pop` 同步，嚴禁在元件建立後直接修改 `stock_input_box`。
* **必留介面元件**：頂部「台股技術與籌碼分析」與版本號上下兩行顯示＋左右切換鈕；頁籤最下方「📌 目前標的」資訊條＋左右切換鈕；參數設定頁籤內「🗑️ 清除分點」與「批次增補指定基準日起往前 N 日分點統計／明細」按鈕。

## 三、 重大問題排錯經驗法則（實戰心法）
1. **問題多次無法解決時，嚴禁在主程式中盲猜硬改**：
   * 應立即將該單一問題**抽離為獨立最小實驗（Standalone Test / Colab 獨立腳本）**，直接驗證真實網址、HTTP 回應編碼（如 `cp950`）、實際 HTML 表格結構與欄位正負號格式，確認抓得到真實資料且解讀完全無誤後，再帶回主系統模組整合。
2. **隱藏頁籤（Hidden Tab）前端繪圖寬度陷阱**：
   * 在 Streamlit 分頁架構中，未預設選取的子頁籤在載入瞬間寬度為 `0`；任何前端圖表（尤其是 `staticPlot: true` 鎖死互動的圖表）不可在寬度為 `0` 時盲目初始化，必須透過 `ResizeObserver` 確認容器展開取得實際螢幕寬度後再行繪製。
