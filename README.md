# 台股技術與籌碼分析系統（tw-stock-Mchart）

## 一、 系統模組架構

- `app.py`：主介面與狀態生命週期（唯一系統版本號權威源，動態掃描各模組最大版本號）[cite: 1]。頂部採三主頁籤架構（`📊 操作儀錶板` / `📈 個股` / `⚙️ 參數設定`），預設收合側邊欄；「個股」主頁籤內含四大子頁籤（`📊 指標` / `💰 籌碼` / `📊 分點統計` / `📈 分點日況`）[cite: 1]。
- `frontend.py`：Plotly 前端圖表、跨圖同步 JS（動態偵測所有 `xaxis\d*` 軸鍵名同步雙次軸平移縮放）、大盤加權（`^TWII`）與櫃買（`^TWOII`）緊緻雙列資訊列與分點雙頁籤（分點統計排行榜、分點日況逐日柱狀圖）HTML 渲染[cite: 1]。
- `chart_builder.py`：K 線主圖（藍色加大標題）、指標頁籤（KD/MACD/OBV/20-120-240-1200日乖離率）與籌碼頁籤建置（個股 6 列副圖；`^TWII` 與 `^TWOII` 專屬緊緻雙列副圖，消除空白區）[cite: 1]。
- `indicators.py`：均線、乖離率、技術指標、5MA 波段轉折、週轉率、大戶週對齊計算，以及 `^TWII` / `^TWOII` 融資金額（億）與融資／融券維持率計算[cite: 1]。
- `data_fetcher.py`：日 K 線、三大法人、個股資券、上市全市場資券（`^TWII`）、上櫃全市場彙總資券（`^TWOII`）、集保大戶、操作儀錶板報價與富邦分點爬蟲引擎[cite: 1]。
- `storage.py`：本地 SQLite（`data_{code}.db`）與歷史紀錄管理（與操作儀錶板自選清單雙向同步，`margin_short` 資料表含 `margin_money_diff` 與 `margin_money_bal` 億元欄位並具備舊庫自動遷移防呆）[cite: 1]。
- `cloud_sync.py`：Google Drive 雙向同步（Service Account / Colab）[cite: 1]。

## 二、 開發防呆憲法（新對話必讀，未經允許嚴禁產出程式碼）

### 1. 程式開發五項紀律與架構鐵律
- **紀律 1（先確認再動手）**：先確認問題與發生原因，再確認解決方案；**必要時須先提供 Colab 測試碼，來做確認**；非得到明確允許，嚴禁擅自產出程式碼。
- **紀律 2（依據 GitHub 實際程式碼修訂）**：維護或修改程式時，不可憑空臆測或依賴舊記憶，必須依據 GitHub 最新原始碼落實修訂。
- **紀律 3（溝通扼要直接）**：初步溝通扼要（40 字內為原則），不復述雙方已知內容，不使用情緒化、誇張或煽情形容詞。
- **紀律 4（附精確修改備註）**：修訂程式碼時，必須在修改處附帶精確的文字備註說明（標註「修改目的」與「防呆防錯原因」），保留修改依據供後續對話追蹤，避免誤刪或重工。
- **紀律 5（局部精準修訂、不重寫）**：僅針對要修訂的部分修改程式碼，未要求修改的部分（尤其已驗證之資料源與既有功能）必須完整保留，不可擅自重寫。
- **交付規範**：提供程式碼時一次只出一個完整檔案，待確認儲存完成後再出下一個；不使用教科書樣本資料敷衍應對。
- **UI 頁籤架構鐵律**：頂部三主頁籤必須維持 `st.radio(horizontal=True)` 模擬分頁外觀，**嚴禁改回 `st.tabs`**（`st.tabs` 無法從程式狀態跳轉，會破壞儀錶板點擊跳轉個股功能）；「個股」內四大子頁籤順序與動態 `chart_id` 隔離機制不可擅自刪減，避免跨頁籤圖表殘留與同步失效[cite: 1]。

### 2. 已驗證網路資料源清冊（嚴禁擅自替換或修改）
- **日 K 線與流通股數**：`yfinance`（主）＋ 證交所 `STOCK_DAY` / 櫃買 `st43_result.php`（補齊延遲日 K；支援含英文後綴之台股 ETF，如 `00632R`、`00664R`、`00679B`、`00631L`）[cite: 1]。
- **三大法人**：證交所 `T86` / 櫃買 `3itrade_hedge_result.php`（主）＋ FinMind `TaiwanStockInstitutionalInvestorsBuySell`（備）[cite: 1]。
- **個股融資融券**：FinMind `TaiwanStockMarginPurchaseShortSale`[cite: 1]。
- **上市大盤全市場資券與融資金額（`^TWII`）**：
  - 主資料源：FinMind `TaiwanStockTotalMarginPurchaseShortSale`（`MarginPurchaseMoney` 原始單位為「元」，除以 `1e8` 換算為「億元」）[cite: 1]。
  - 備援補齊最新交易日：證交所 `MI_MARGN`（`融資金額(千元)` 原始單位為「千元」，除以 `1e5` 換算為「億元」）[cite: 1]。
- **櫃買指數全市場彙總資券與融資金額（`^TWOII`）**：
  - 主資料源：嗨投資（HiStock）`https://histock.tw/stock/three.aspx?m=mg&no=TWOI`（直接取得已彙總欄位：日期、融資餘額(億)、融資增加(億)、融券餘額(張)、融券增加(張)）[cite: 1]。
  - **資料源事實鐵律**：上櫃全市場彙總來源無全市場「融資張數」欄位，故 `margin_diff` / `margin_bal` 明確設為 `0.0`，圖表僅繪製融券增減（千張）與融資金額增減（億元），**嚴禁將融資金額誤充當張數，亦嚴禁逐檔抓取 900 多檔上櫃個股加總**[cite: 1]。
- **集保大戶持股**：
  - **歷史分級查詢（約 15 週，1～15 級）**：集保官網歷史查詢頁面 `www.tdcc.com.tw/portal/zh/smWeb/qryStock`（先 GET 取得表單隱藏欄位與下拉選單 `<option>` 之所有可用公告週別 `YYYYMMDD`，比對本地 `shareholding_distribution` 篩出缺失週別後，再逐週 POST 查詢並每次更新最新核發之 `SYNCHRONIZER_TOKEN`，解析含 `"1,000,001"` 表格寫入資料庫；嚴格限定 `1 <= level <= 15`，排除第 16、17 合計列）[cite: 1]。
  - **最新單週全市場批次補齊**：集保開放資料 `opendata.tdcc.com.tw/getOD.ashx?id=1-5`（取最新單一公告日 `1～15` 級）[cite: 1]。
  - **嚴禁使用 FinMind 免費版作為集保大戶資料源或備援**：經實測 FinMind 免費版不開放 `TaiwanStockHoldingSharesPer`（僅回傳升級贊助訊息），呼叫只會造成無效等待[cite: 1]。
- **券商分點進出**：富邦 e點通（`fubon-ebrokerdj.fbs.com.tw`）[cite: 1]。
  - **區間與單日進出排行（含歷史單日）**：統一使用 `z/zc/zco/zco.djhtm?a={code}&e={start_date}&f={end_date}`（單日查詢時 `e` 與 `f` 帶入同一交易日即可精準取得歷史單日排行）[cite: 1]。
  - **網頁結構與正負號解讀鐵律**：頁面為**同一張 10 欄並排表格**（前 5 欄為買超券商、後 5 欄為賣超券商），且網站原始 HTML 中「賣超前 10 名」的買賣超張數欄位是以**正數**呈現，解析時必須強制正規化為負值（`-abs(net_val)`），前端統一顯示「買超紅字＋號、賣超綠字－號」[cite: 1]。
  - **單一分點逐日進出明細**：由排行表分點名稱連結解析出 `zco0` 網址並帶入區間參數 `c={start_date}&d={end_date}` 擷取逐日買賣超序列，增量累積寫入 `broker_daily_trades` 資料表並同步雲端[cite: 1]。
  - **時間基準防呆**：每個交易日 `15:00`（含）前預設分點基準日對齊「前一交易日」（跳過週六日），`15:00` 後才對齊當日[cite: 1]。

### 3. Streamlit Cloud 部署與維運經驗守則
- GitHub 更新 `.py` 程式碼後，Streamlit Cloud 會自動熱更新（約 3～5 秒），**非必要不按 `Reboot app`**（按 `Reboot app` 會重建容器並重裝 102 個套件，耗時約 40～60 秒）。
- 若日誌顯示 `Uvicorn server started` 但左側畫面仍轉圈，直接按瀏覽器重新整理（F5 / Ctrl+R）即可載入新畫面。
